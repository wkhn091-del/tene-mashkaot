# הצעת ריטיינר ביצועים ואבטחה (לשליחה כשבוע אחרי מסירה)

נושא: שמירה על האתר מהיר ובטוח — תנא משקאות

היי,

שבוע אחרי העלייה כדאי לנעול תחזוקה שוטפת. חנות אונליין היא מערכת חיה: עדכוני אבטחה, תלויות, תשלומים ומדידה.

**מה כוללת חבילת הריטיינר (טיוטה — סכום לאישור):**
- עדכוני אבטחה חודשיים ותלויות (npm audit על High/Critical)
- ניטור התראות Sentry
- בדיקת גיבוי Sanity + תרגול Rollback ב־Vercel
- סיבוב מפתחות תקופתי (webhooks / API)
- מעקב Web Vitals (LCP/INP) ושמירה על יעד 60FPS ב־Hero
- פגישת אופטימיזציה חודשית על Clarity + GA4

**מה לא כלול:** פיצ׳רים חדשים, סצנות 3D חדשות, קמפיינים, צילומים.

אשמח לתאם סכום ו־SLA מדויק לפי היקף התמיכה שתרצו.
