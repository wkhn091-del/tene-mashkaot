# תסריט סרטון הדרכה — מנהל החנות

משך משוער: 8–10 דקות.

---

### סצנה 1 — כניסה
**[עכבר]** פותחים `/studio`, מתחברים.  
**הקראה:** «זה לוח הניהול. כל מה שמופיע באתר עובר מכאן. אחרי שינוי תמיד Publish.»

### סצנה 2 — מוצר חדש
**[עכבר]** Products → Create → ממלאים שם בעברית, מחיר כולל מע״מ, קטגוריה, תמונה, inStock.  
**הקראה:** «המחיר באתר כולל מע״מ. אם המוצר אזל — מכבים במלאי. הלקוח יראה כפתור וואטסאפ במקום הוספה לסל.»

### סצנה 3 — מבצע עם תאריך סיום
**[עכבר]** Promotions → percentOff / giftThreshold → startsAt / endsAt / active.  
**הקראה:** «רק מבצע פעיל עם תאריך עתידי מציג ״עד תאריך״ באתר. אין ספירה לאחור מזויפת.»

### סצנה 4 — הזמנה נכנסת
**[עכבר]** Orders → פותחים הזמנה → סטטוס / תשלום.  
**הקראה:** «התראה גם מגיעה למייל ולוואטסאפ החנות. לקוח יכול לעקוב ב־/orders עם מספר הזמנה וטלפון.»

### סצנה 5 — באנר ושעות
**[עכבר]** Site settings → announcement, opening hours.  
**הקראה:** «הבאנר העליון משתנה אוטומטית בשבת. כשפתוחים — מופיע משלוח היום לפי שעות אמיתיות.»

### סצנה 6 — אבטחה
**[עכבר]** לא מציגים טוקנים.  
**הקראה:** «לא שולחים סיסמאות. לא פותחים קבצי CSV ממקור לא מוכר. MFA דלוק תמיד.»
