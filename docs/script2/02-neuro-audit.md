# סקריפט 2 מודול ג׳ — סימולציית לקוח אכזרית

**פרסונה:** תושב/ת אלעד, צריך יין/מארז היום או מחר, משווה מחיר בוואטסאפ מול חנויות, לחוץ בזמן, במובייל 375px.

## 1) 5 שניות ראשונות
- Age gate קודם — חיכוך מכוון (חוק 18); אחרי אישור: Hero עם סטטוס פתיחה + משלוח חינם + CTA חנות/וואטסאפ.
- באנר עליון: פתוחים / אותו־יום / שבת — ברור.
- **סיכון:** אם אין מוצרים בסטודיו — featured empty → WA (טופל). אם Hero כבד במובייל — יש poster/fallback.

## 2) מסע גלילה
- קטגוריות → מבצעים → featured → pour → מתנות → אירועים → ביקור.
- CTA דביק במוצר/סל/קופה; וואטסאפ צף מורם מעליו.
- **חיכוך:** אורך דף הבית; PourShowcase עלול להסיח — נשאר לפי נעילת Tier 3.
- Fitts: כפתורי sticky במובייל — קיימים.

## 3) אמון
- כשרות בד״ץ אלעד, כתובת אמיתית, טלפון, Google Reviews.
- מחיר כולל מע״מ; אין «לפני» פיקטיבי.
- תמונות חנות אמיתיות באווירה; מוצרים תלויים בהעלאה בסטודיו.

## 4) Checkout
- Guest; Turnstile; honeypot; שדות מינימליים יחסית.
- אותו־יום מוצג; קופון קיים.
- **סיכון:** CAPTCHA אם Turnstile לא מוגדר ב־env — צריך לוודא בפרוד.

## 5 תיקוני חירום (סטטוס)
1. באנר הזמנות חי — **בוצע**
2. OOS→WA — **בוצע**
3. אותו־יום אמיתי — **בוצע**
4. Reviews מוקדם — **בוצע**
5. העלאת מוצרים אמיתיים לסטודיו — **תוכן, באחריות הלקוח**
